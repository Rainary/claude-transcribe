# claude-transcribe

🇬🇧 [English version](README.en.md)

Скилл для Claude Code: аудио или видео → расшифровка → спикеры → готовое
мемо. Полностью локально на Apple Silicon — без API-ключей, токенов и
интернета после установки.

Кидаешь файл созвона — через пару минут получаешь документ: решения, действия
с владельцами, открытые вопросы и полная расшифровка по репликам с
таймкодами. Единственное, что спросит скилл, — как зовут спикеров.

## Что внутри

- **Транскрипция**: [mlx-whisper](https://github.com/ml-explore/mlx-examples)
  с `whisper-large-v3-turbo` (для сложных записей — флаг на полный large-v3).
- **Защита от галлюцинаций Whisper**, двухслойная: Silero VAD вырезает
  длинные паузы до модели (галлюцинации рождаются на тишине), а чёрный
  список добивает классику вроде «Субтитры сделал DimaTorzok» и
  «Продолжение следует…».
- **Диаризация**: [senko](https://github.com/narcotic-sh/senko) на
  CoreML/ANE — час аудио размечается по спикерам за секунды, HuggingFace-токен
  не нужен.
- **Чистка речи** — детерминированная, в скрипте: междометия («э-э», «мм»),
  повторы служебных слов («я я хотел»), вводные паразиты. Смысловые повторы
  и характерные словечки не трогаются.
- **Мемо по типу записи**: созвон (решения / действия / открытые вопросы),
  интервью (инсайты / боли / цитаты), лекция (конспект), голосовая заметка.
  Тип определяется по содержанию — анкет нет.
- **Редактура из коробки**: правила текста мемо (честность, инфостиль,
  анти-нейрослоп) и типограф русского текста (ёлочки, тире, неразрывные
  пробелы) встроены в скилл.

## Скорость

Ориентиры на ноутбуке с чипом M-серии (реальные записи, не синтетика):

- Транскрипция идёт в ×15–20 от реального времени: час записи — 3–4 минуты,
  сорокаминутная лекция — около двух.
- Диаризация часа аудио — меньше минуты.
- Связка large-v3 без VAD на тех же файлах в 2–3 раза медленнее при том же
  качестве на русском.

LLM в пайплайне не переписывает транскрипт — вся механическая работа сделана
скриптами, Claude пишет только мемо. Это и скорость, и экономия токенов.

## Требования

- Mac на Apple Silicon (M1+), macOS 14+.
- Python 3.11 — если нет, `setup.sh` сам скачает официальный установщик
  и откроет его (единственный ручной шаг, нужен пароль администратора).
- ffmpeg — если нет, `setup.sh` поставит через Homebrew.
- Место: ~1,6 ГБ модель Whisper (скачается при первом запуске) и ~2 ГБ venv.

## Установка

Как плагин Claude Code:

```text
/plugin marketplace add Rainary/claude-transcribe
/plugin install transcribe@claude-transcribe
```

Или одной командой без плагин-системы:

```bash
curl -fsSL https://raw.githubusercontent.com/Rainary/claude-transcribe/main/install.sh | bash
```

После установки скажи Claude Code: «проверь окружение transcribe» — он
прогонит `--check` и, если чего-то не хватает, запустит доктора.

## Использование

В Claude Code, человеческим языком:

```text
расшифруй ~/Desktop/созвон.mov
сделай конспект из ~/Downloads/лекция.mp4
```

Флаги на особые случаи (Claude применит их сам, если попросить):
`--model large` — максимальное качество, `--language ru|en` — если
автодетекция ошиблась, `--precise` — пословные таймштампы, `--no-vad`,
`--no-cleanup`.

Форматы: mp3, wav, m4a, ogg, webm, flac, aac, opus, mp4, mov, mkv, m4v, avi.

## Как это устроено

```text
файл → ffmpeg (16 кГц моно) → Silero VAD (речевые зоны)
     → mlx-whisper по зонам → чёрный список галлюцинаций → чистка паразитов
     → senko (спикеры) → сопоставление по таймкодам → transcript.md
     → Claude: мемо по правилам references/memo-style.md → типограф → документ
```

Каждый запуск складывает в свою папку `meta.json` (статистика: скорость,
язык, сколько галлюцинаций выброшено), `segments.json`, `transcript.txt`
и `transcript.md`.

## Ограничения

- Только Apple Silicon: транскрипция держится на MLX, диаризация — на CoreML.
- Чистка речи и чёрный список галлюцинаций заточены под русский; сам Whisper
  мультиязычен, на английском всё работает, на других языках — не проверялось.
- Наложение реплик (два голоса одновременно) — слабое место любого ASR:
  такие места могут расшифроваться неточно.
- Диаризация требует Python 3.11 (колесо senko для macOS собрано под cp311).

## Планы

- Live-режим: запись созвона (системный звук + микрофон, без бота в звонке)
  с транскрипцией по ходу — мемо через минуту после конца встречи.
- Опциональный fast-режим на parakeet-tdt (ещё ~5× быстрее turbo).
