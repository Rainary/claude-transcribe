# Changelog

## 1.0.0 — 2026-09-06

Первый публичный релиз.

- Транскрипция через mlx-whisper (`large-v3-turbo` по умолчанию, `--model
  large` для сложных записей), полностью локально на Apple Silicon.
- Silero VAD: длинные паузы вырезаются до модели — профилактика галлюцинаций
  Whisper на тишине плюс ускорение.
- Чёрный список типовых русских галлюцинаций («Субтитры сделал DimaTorzok»,
  «Продолжение следует…») как вторая линия обороны.
- Детерминированная чистка речевых паразитов («э-э», «ну,» в начале фразы,
  повторы служебных слов) — без участия LLM.
- Диаризация через senko (CoreML/ANE): автоматическое число спикеров, без
  HuggingFace-токена; `--rename` применяет имена без правки текста руками.
- Разбивка транскрипта на абзацы по паузам с таймкодами (`transcript.md`).
- Автоопределение типа записи (созвон / интервью / лекция / заметка) по
  содержанию — без анкетирования пользователя; шаблон мемо под каждый тип.
- Редакторские правила итогового мемо (`references/memo-style.md`, по мотивам
  slopotron и chukovsky) и встроенный типограф русского текста
  ([milchin](https://github.com/beaverbeard/milchin) © beaverbeard, MIT) —
  из коробки.
- `setup.sh` — идемпотентный доктор окружения: venv, пакеты, ffmpeg через
  brew; установку Python 3.11 доводит до одного клика.
- Восстановление повреждённых зон транскрипта (`repair_segments.py`) как
  запасной инструмент.
